# Rotulagem Nutricional — ANVISA

## Legislação aplicável

- **RDC 429/2020** — regras gerais de rotulagem nutricional
  - PDF: https://bvsms.saude.gov.br/bvs/saudelegis/anvisa/2020/RDC_429_2020_.pdf
- **IN 75/2020** — porções padronizadas e formatos de tabela
  - PDF: https://bvsms.saude.gov.br/bvs/saudelegis/anvisa/2020/IN%2075_2020_.pdf

## Nutrientes obrigatórios

Valor energético, Carboidratos, Açúcares totais,
Açúcares adicionados, Proteínas, Gorduras totais,
Gorduras saturadas, Gorduras trans, Fibra alimentar, Sódio

## Limites para rotulagem frontal (lupa "ALTO EM")

| Nutriente            | Sólidos      | Líquidos      |
| -------------------- | ------------ | ------------- |
| Açúcares adicionados | ≥ 15g/100g   | ≥ 7,5g/100ml  |
| Gorduras saturadas   | ≥ 6g/100g    | ≥ 3g/100ml    |
| Sódio                | ≥ 600mg/100g | ≥ 300mg/100ml |
